# POOL BATTLE Member & Admin System

ระบบสมาชิกและศูนย์ควบคุมสนาม POOL BATTLE รองรับมือถือและคอมพิวเตอร์ เชื่อมข้อมูลแบบถาวรด้วย Cloudflare D1 และเก็บรูปสมาชิกใน R2

## ระบบสมาชิก

- สมัครและเข้าสู่ระบบด้วยเบอร์มือถือ พร้อมตั้งรหัสผ่านส่วนตัวครั้งแรก
- ซื้อบัตรเข้า 150 บาทได้หลายใบ โดยระบุเบอร์ ชื่อเล่น และรูปสมาชิกทุกใบ
- บัตรผ่านประตูแสดงรูป Player ID, QR สมาชิก และสิทธิ์ของรอบปัจจุบัน
- บัตรแข่งขันราคาเกมละ 100 บาท ซื้อขั้นต่ำ 5 เกม พร้อมแสดงยอดซื้อทั้งหมดและเกมพร้อมใช้
- ตัดรอบบัตรทุกวันเวลา 17:00 น. ตามเวลาประเทศไทย
- สมาชิกเปลี่ยนรูปโปรไฟล์จากกล้องหรือรูปในเครื่องได้
- QR สมาชิกเปิดหน้าพนักงานเพื่อบันทึกผลการแข่งขัน

## ระบบหลังบ้าน Admin

- Dashboard สมาชิก บัตร รายได้ คิว โต๊ะ ผลรอตรวจ กองรางวัล และความเสี่ยง
- จัดการโต๊ะ คิว สมาชิก พนักงาน การแข่งขัน ข่าวสาร และการตั้งค่า
- อนุมัติหรือปฏิเสธผลการแข่งขันก่อนลง Monthly/Lifetime Points
- ตารางคะแนนและกองรางวัลรายเดือน 40/25/15/12/8
- Audit Trail สำหรับการเปลี่ยนแปลงสำคัญด้านเงิน คะแนน และสิทธิ์

เส้นทางหลัก: `/` ระบบสมาชิก, `/admin` ระบบหลังบ้าน และ `/staff/result` หน้าบันทึกผลการแข่งขัน

## เริ่มใช้งาน

```bash
npm install
npm run dev -- --hostname 127.0.0.1
```

ตรวจคุณภาพก่อนเผยแพร่:

```bash
npm run lint
npm run build
```
